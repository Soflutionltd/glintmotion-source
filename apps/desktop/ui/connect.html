Connecter

Pilote Glintmotion depuis ton agent

Cursor, Claude Code ou tout agent compatible MCP peuvent ouvrir tes projets, regarder l'aperçu, modifier les éléments et exporter la vidéo. Glintmotion doit rester ouvert.

Cursor

À ajouter dans ~/.cursor/mcp.json, sous mcpServers.


      


      

        

          
Claude Code

Autre agent

          
        

        
Serveur MCP en HTTP, avec cet en-tête d'autorisation.

        

      


      

        

          
Terminal

          
        

        

          La commande glintmotion lance le moteur de l'app : mêmes commandes que
          npx hyperframes, sans rien télécharger.
        

        
glintmotion check --json
glintmotion timeline --json
glintmotion snapshot --at 2,5

      


      

        

          
Compétences

          
        

        

          Les guides que l'agent lit avant d'écrire : composition, animation, sous-titres, et
          motion-quality pour un texte qui bouge net. Pour Claude Code et Cursor, dans
          ~/.claude/skills et ~/.cursor/skills. Ce qui s'y trouve déjà sous le même
          nom est mis de côté, pas supprimé.
        

      


      

        Le serveur n'écoute que sur ce Mac. Le jeton reste dans les réglages de Glintmotion :
        ne le partage pas.
